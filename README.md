## 1. 项目简介

### 1.1 产品定位

**此刻地图** 是一款基于地理位置的实时社交工具。它以"地图"为界面、以"气泡"为语言——用户可以在当前位置发布即时信息（求助、组队、推荐、避雷、见闻、建群），同一时空下附近的人几秒内即可看到并回应。

我们想解决你在线下活动现场**最普遍、却最被忽视**的四个痛点：

| 痛点 | 说明 |
| --- | --- |
| **临时组队难** | 音乐节想拼车、想看展但朋友没空，附近找不到合适的人 |
| **现场信息差** | 队伍排多长？哪个摊位值得逛？周边哪家店不踩雷？ |
| **即时求助无门** | 东西丢了、需要充电宝、临时找厕所，身边全是陌生人却张不开嘴 |
| **同好难觅** | 身边站着一群和你喜欢同一支乐队的人，却只能各自沉默 |

> 我们不替代小红书做行前攻略，也不替代高德做行中导航。我们专注 **"你已经在现场"** 之后的那段时间。

* **核心形态**：H5 页面 + Node.js WebSocket 后端
* **目标用户**：18-35 岁、喜欢线下探索、需要在陌生地点快速找到同好的人群
* **当前版本**：`A1.0.3`（EL 大赛参赛版本）

### 1.2 与现有工具的差别

| 工具 | 局限 | 此刻地图 |
| --- | --- | --- |
| **小红书 / 微博** | 内容是过去式的攻略，无法满足"此刻此地"的需求 | 信息按地理位置锚定在地图上，时效性强 |
| **微信群 / QQ群** | 信息容易淹没，建群流程繁琐，难以匹配到现场的人 | 一键建群气泡，无需加好友即可入群 |
| **高德 / 大众点评** | 静态的地点信息，缺少现场动态与同好连接 | 气泡带位置、带类型、带互动，现场动态实时更新 |

### 1.3 设计理念

#### 「此刻即响应」
- 技术上，**WebSocket 全双工长连接**，新气泡、新消息的推送延迟控制在秒级
- 功能上，摒弃"瀑布流"信息轰炸，以**地理围栏 + 时效性**作为信息分发基础
- 你看到的永远是**此刻、此地、与我相关**的动态

#### 「地图即界面，气泡即语言」
- 用大众熟悉的地图作为主视觉，零学习成本
- 4 步完成发布，浏览信息像查看地图标注一样简单
- 表达、求助、组队、分享，都通过这张"活的地图"发生

## 2. 快速上手

### 2.1 界面速览

```
┌──────────────────────────────┐
│  🗺️  地图（主区域）             │
│                              │
│   ●  你的位置                  │
│   ⓘ  气泡（按类型有不同图标）    │
│   ◯  范围圈（你的可见边界）      │
│                              │
│                       [+]    │ ← 发气泡
│                  [📍]  [👤]  │ ← 重新定位 / 个人中心
└──────────────────────────────┘
```

**顶部入口**：
- 🔍 搜索地点 / 活动
- 💬 收件箱（带未读数角标）
- ⚙️ 设置

### 2.2 4 步发布一个气泡

从打开地图到成功发布，**只需 4 步**：

```
选定位  →  点 +  →  选类型 / 填内容  →  确认位置 → 发布
```

1. 选定你的中心位置（默认 GPS，可搜索切换）
2. 点击右下角 **+** 按钮
3. 选气泡类型（6 选 1，必选）、填标题/正文/图片、选活动类型（非必选）、选有效期
4. 确认位置点（可微调）→ 发布

> 气泡有效期一到，**自动从地图上消失**，不会留陈旧信息。

### 2.3 小贴士

- **长按**地图某点 → 快速在该位置发气泡
- **双指捏合** → 缩放；**双指拖动** → 倾斜视角
- 气泡详情里**向上滑** → 完整评论
- 顶部的"+发布"和右下角的"+"都能发气泡
- 设置**有效期**为最短 15 分钟，**试错成本低**
- 发布时勾选"活动类型"标签，能让对的人更容易找到你
- **建群气泡**解散条件：发布 24 小时后，参与人数 ≤ 2（含发起人）
- 设置"状态"为"空闲可约"或"寻找同伴"时，**附近的人会优先看到你**

## 3. 核心功能

### 3.1 气泡：6 种类型

发气泡时，必须从以下 6 种类型中**选择 1 个**：

| 图标 | 类型 | 适用场景 |
| --- | --- | --- |
| 🆘 | **求助** | 临时找厕所、丢失物品、求充电宝、紧急情况 |
| 🤝 | **组队** | 拼车、拼桌、拼场地、需要同行者 |
| 💬 | **建群** | 想就地建一个临时聊天室 |
| ⭐ | **推荐** | 这家店不错、这个摊位很值、这个机位好看 |
| ⚠️ | **避雷** | 这里排队太长、这家踩雷、注意安全 |
| 👀 | **见闻** | 偶遇精彩瞬间、想分享此刻感受 |

**附加选项**（非必选）：
- **活动类型**：自然风景 / 展览演出 / 体育活动 / 好吃好喝 / 人文历史 / 其他（可多选）
- **图片**：最多可附 1 张图
- **有效期**：15 / 30 / 60 / 120 分钟（默认 60 分钟）
- **隐私**：设为"公开"则所有人可见；设为"私密"则仅自己可见且**永久保存**（不受时效影响），适合记录足迹、纪念日打卡、个人心情

### 3.2 建群气泡：一键开一个临时聊天室

> 这是"此刻地图"最独特的玩法。

1. 发布气泡时选 **建群** 类型，填好聊天室名称（如"草莓音乐节 D3 出口一起拼车回市区"）
2. 发布后，这个气泡**本身就是聊天室入口**
3. 任何看到气泡的人，**无需加好友、无需群主审核**，点击即进入聊天
4. **自清理机制**：若建群气泡发布 24 小时后，聊天室人数 ≤ 2（含发起人），自动解散，气泡同步消失

适合：音乐节拼车、漫展同好、校园活动临时小组、citywalk 临时团。

### 3.3 地图与定位机制

#### 三种使用状态

| 状态 | 中心点 | 默认范围 | 适合 |
| --- | --- | --- | --- |
| **默认状态** | 你的真实 GPS 位置 | 5 公里 | 下班路上随便看看附近有啥 |
| **搜索定位** | 你搜的地点或活动（如"草莓音乐节"） | 可调 | 周末想重点看某场活动 |
| **校园/商圈定位** | 固定地点（如"同济四平路校区"、"XX 商圈"） | 1 公里内 | 校园活动、市集逛街 |

#### 6 档可见范围

你随时可以调整可见范围（共 6 档）：

```
100 米 → 500 米 → 1 千米 → 2 千米 → 3 千米 → 4 千米
```

调整后，**地图上会有一个可视化的圆圈**实时显示你的可见边界——这是"此刻地图"的独家设计，让你对"我能看到多远"有清晰认知，避免误判。

#### 典型使用场景

- **下班路上看一眼**：保持默认状态，看 5 公里内有没有小展、路演、市集
- **周末去特定活动**：搜索"草莓音乐节"→ 地图飞过去 → 选 1 公里范围 → 看场地内拼车、排队、见闻
- **在商圈逛街**：搜索"XX 商圈"→ 选 500 米范围 → 重点看这片区域里别人的推荐与避雷
- **校园内活动**：定位到"XX 大学 XX 校区"→ 选 1 公里范围 → 看校内求助、组队、失物招领

### 3.4 状态标识：让"此刻"被看见

进入个人主页，你可以设置**6 种预设的场景化状态**：

| 状态 | 含义 |
| --- | --- |
| 🟢 **空闲可约** | "可以来找我玩/聊天" |
| 🚶 **正在路上** | 正在前往某地 |
| 🎉 **活动 ing** | 正在参与某活动 |
| 🤝 **乐于助人** | 愿意回应别人的求助 |
| 🔍 **寻找同伴** | 想找人一起 |
| 🔕 **暂时勿扰** | 限制陌生人私聊 |

- 设为"暂时勿扰" → 系统**限制陌生人发起私聊**，尊重你的边界
- 设为"空闲可约" → 隐含发出社交信号，附近的人更可能来找你

> 状态不是静态签名，而是**可驱动行为的动态信号**。

### 3.5 社交互动

#### 基础互动（在气泡详情页）
- 点赞 / 收藏 / 评论 / 转发
- 一键向发布者**发起私聊**（适合拼车费用分担、见面地点确认等具体协商）
- 互为好友后，可在**收件箱**中发起好友群聊

#### 加好友
- 在别人头像 / 气泡详情里点"加好友"
- 对方在**收件箱**收到申请
- 同意后出现在你的好友列表

#### 创建群聊（好友群）
- 私聊界面右上角 **+**
- 选好友 → 创建
- 群消息所有人实时收到

#### 加群聊天室（建群气泡）
- **无需加好友**，点击气泡即进入

### 3.6 筛选与发现

气泡多了怎么办？用 **"范围 + 标签"** 双重筛选：

1. **调整范围**：缩到 100 米看眼前；放到 5 公里看周边
2. **按气泡类型筛**：只看"组队"、只看"推荐"、只看"避雷"
3. **按活动类型筛**：只看"展览演出"、只看"好吃好喝"

> 未来会引入简单推荐逻辑，根据你的兴趣优先展示相关气泡。

### 3.7 个人中心 6 个 Tab

| Tab | 内容 |
| --- | --- |
| 我的发布 | 我发过的所有气泡 |
| 我的点赞 | 我点过赞的 |
| 我的收藏 | 我收藏的 |
| 我的评论 | 我评论过的 |
| 历史浏览 | 我看过的气泡 |
| 气泡搜索 | 在个人中心内搜索 |

## 4. 典型场景示例

### 场景 1：音乐节

> 你一个人去草莓音乐节，结束后想找附近的人拼车回市区。

1. 打开"此刻地图"，搜索"草莓音乐节"→ 定位过去
2. 选 1 公里范围，看到所有场内气泡
3. 找到有人发的 **🤝 组队** 气泡"东门拼车回市区，还有 2 个座位"
4. 点击进入 **💬 私聊** 协商具体时间地点
5. 或者有人发了 **💬 建群** 气泡"散场拼车群" → 直接进群喊一声

### 场景 2：逛漫展

> 你在漫展看到一个超棒的 coser 想合影，但身边没朋友。

1. 发布一个 **👀 见闻** 气泡"求 coser 合影搭子，A 馆"
2. 几秒后，附近的人看到，可能直接发 **🤝 组队** 回应你
3. 或者直接进一个"漫展搭子" **💬 建群** 聊天室

### 场景 3：临时求助

> 你在一个陌生商圈突然内急，找不到厕所。

1. 发布一个 **🆘 求助** 气泡"求最近的公共厕所位置！急！"
2. 附近的人看到会回复具体位置（公开气泡是所有人可见）
3. 完事后记得把气泡设为**私密**，作为个人记录保存

### 场景 4：citywalk

> 你和朋友约了周末去老城区 citywalk，但朋友临时有事。

1. 发一个 **🤝 组队** 气泡"周日下午老城区 citywalk 缺 1 个搭子"
2. 几小时内，可能会有同好看到并回应
3. 也可以直接建 **💬 建群** 气泡"老城区 walk 临时群"，让感兴趣的人先进来聊

### 场景 5：校园十大歌手

> 学校有十大歌手决赛，你想找同学一起去看。

1. 定位到学校，1 公里范围
2. 发 **🤝 组队** 气泡"今晚十大歌手有人一起吗？B 区座位"
3. 也可能看到别人发的 **⭐ 推荐** 气泡"演出 8 点开始，建议提前 1 小时到场"

### 场景 6：校园失物招领

> 你下课回宿舍路上发现教学楼 3 楼有同学落下了一个黑色钱包，喊了一声没人应。

1. 打开"此刻地图"，定位到"XX 教学楼"，范围 100 米
2. 发一个 **🆘 求助** 气泡"教学楼 3 楼 305 门口捡到一个黑色钱包，失主看到请私聊认领"（带 1 张图）
3. 失主（或知情同学）看到后会直接发起 **私聊** 跟你联系
4. 同时建一个 **💬 建群** 气泡"本周失物招领群"，让近期丢东西的同学都能进来互通

> 反过来，你丢了校园卡：
> 1. 发 **🆘 求助** 气泡"刚在食堂二楼丢了一张蓝色校园卡，拾到者请私聊，必有重谢"
> 2. 拣到的同学可一键发 **私聊** 给你，约时间地点归还
> 3. 你也可以去"失物招领" **💬 建群** 群里喊一声

### 场景 7：选课/二手交易

> 新学期开学，你想找同学拼二手教材或换课。

1. 发 **🤝 组队** 气泡"求《高等数学（下）》二手教材，原价 35，可刀"
2. 或发 **💬 建群** 气泡"XX 专业 2024 级二手书群"，大家进来自由交易
3. 有人响应后发 **私聊** 约线下交付地点（一般是宿舍楼下或教学楼）

### 场景 8：社团招新

> 你在负责社团招新，想让更多同学看到。

1. 定位到社团摊位（如"大学生活动中心门口"），范围 200 米
2. 发 **⭐ 推荐** 气泡"🎤 吉他社招新！现场试听+送周边，10 分钟学会一首歌"
3. 配 1 张摊位照片，让大家能直接找到你
4. 再发 **💬 建群** 气泡"吉他社咨询群"，感兴趣的人先进群问问题

### 场景 9：自习室占座

> 期末周图书馆爆满，你占了一个 6 人桌，同学问能不能一起。

1. 发 **🤝 组队** 气泡"图书馆 3 楼靠窗有 2 个空位，可一起自习到 22:00"
2. 一起自习的同学可以现场扫码加好友，长期组个"期末学习搭子"群
3. 自习完可发 **👀 见闻** 气泡"今天 3 楼 218 桌位置安静，自习到 22:30 人也不多"

### 场景 10：校园跑腿/外卖拼单

> 你想点外卖但起送价太高，想找人拼单。

1. 发 **🤝 组队** 气泡"南区食堂麦当劳拼单，可省配送费 6 元，20:00 前凑齐"
2. 凑齐后建 **💬 建群** 气泡"麦当劳拼单群"，方便实时同步送餐状态
3. 餐到了发 **👀 见闻** "已到南区 2 号楼楼下，自取"——同区域订餐的同学一搜便知

### 场景 11：宿舍搬迁/搬行李

> 大四毕业或换宿舍，行李多一个人搬不动。

1. 发 **🤝 组队** 气泡"周日搬家，紫荆 13 号楼 → 校外，缺 2 个壮丁，可付 50/人"
2. 愿意帮忙的同学发 **私聊** 协商时间
3. 完事可发 **⭐ 推荐** 气泡"感谢 @张三 @李四 帮忙搬家，靠谱！"

### 场景 12：考前冲刺/资料共享

> 考前发现手里资料不全，想找同班同学互通有无。

1. 发 **🤝 组队** 气泡"求《数据结构》期末复习笔记，最好带重点标注"
2. 愿意分享的同学可发 **私聊** 直接发文件
3. 也可建 **💬 建群** 气泡"信科 2022 级期末复习互助群"，考前一周临时搭伙

### 场景 13：跑校园马拉松/夜跑

> 晚上想找人一起夜跑。

1. 发 **🤝 组队** 气泡"今晚 21:00 操场 3 圈夜跑，配速 6'30''，求搭子"
2. 找到搭子后一起打开"显示附近用户"，实时看到对方位置
3. 跑完可在 **💬 建群** 群里打卡，互相激励

### 场景 14：社团活动临时通知

> 你是社团负责人，活动开始前 1 小时发现有变动。

1. 进入之前建好的"社团活动群" **💬 建群** 气泡
2. 群发一条消息："活动地点改到科学楼 302，请大家准时到"
3. 或发一条新 **⭐ 推荐** 气泡，定位到新地点，让没进群的同学也能看到

### 场景 15：校园讲座/分享会

> 你想去听一场讲座，担心找不到位置或现场冷清。

1. 提前发 **🤝 组队** 气泡"今晚 19:00 人文讲座有人一起吗？可讨论"
2. 现场再发 **⭐ 推荐** 气泡"讲座干货笔记已整理，扫码进群共享"
3. 完事发 **👀 见闻** 气泡"今天讲座 100 人到场，反响不错"

### 场景 16：跨校区通勤拼车

> 你在同济四平路，朋友在嘉定校区，周末想约出来。

1. 发 **🤝 组队** 气泡"周六 13:00 嘉定 → 四平 求拼车，可分摊 30 元"
2. 也可建 **💬 建群** 气泡"嘉定⇋四平周末拼车群"，长期复用
3. 拼到人后发 **私聊** 协商具体接驳点（嘉定校区东门 / 地铁站）

## 5. 隐私与安全

> "此刻地图"在隐私上坚持 **"最小必要 + 用户可控"**。

* **位置**：仅在打开应用时使用，不会上传历史轨迹
* **手机号**：仅用于注册，不会展示给其他用户
* **谁能看到我**：
  - 默认**无人可见**（你关闭了"显示附近用户"）
  - 开启后，**你设置的范围圈内的用户**会看到你
* **谁能私聊我**：默认仅好友，或同意过的好友申请；可设"暂时勿扰"限制陌生人
* **气泡隐私**：
  - 公开气泡：所有人可见，到期自动消失
  - 私密气泡：仅自己可见，**永久保存**
* **退出登录**：设置 → 退出登录
* **删除账号 / 数据**：设置 → 反馈，附上注册手机号，后台处理

## 6. 遇到问题？

### 看不到气泡
- 缩小地图（双指捏合 / 滚轮）
- 调整可见范围（试试放大到 5 公里）
- 检查网络（应用需要联网）
- 确认位置权限已开

### 发不了气泡
- 检查是否登录
- 检查是否选了气泡类型（6 选 1，必选）
- 标题 / 内容不能全为空
- 私密气泡可以不发位置，但公开气泡必须有位置

### 搜索不到城市 / 地区
- 确认搜索词是省份或城市全称
- 网络异常时可能搜索失败，重试即可

### 收不到私聊消息
- 检查网络
- 在"收件箱"看是否被过滤
- 对方是否设了"暂时勿扰"

### 想彻底删除我的账号 / 数据
- 设置 → 反馈
- 后台管理员处理（请附上注册手机号）

### 应用卡顿
- 关闭"显示附近用户"，能省很多资源
- 减少同时打开的面板数
- 切到"搜索定位"模式后改回"GPS 定位"
- 把范围缩小（如 500 米以内）

## 11. WebSocket 消息协议

前后端通过 WebSocket 通信（端口 3000）。客户端 `socket.send(JSON.stringify({ type: "xxx", ... }))`，服务端按 `data.type` 分发。

消息类型分类（**共计 60+ 种**，详见 SERVER.js）：

### 认证 / 用户
* `register` / `authLogin` / `login` — 注册与登录
* `queryUserByIdOrPhone` — 按 ID 或手机号查用户
* `getUserFullInfo` / `getUserCenterData` — 拉取用户完整信息
* `updateUserInfo` / `updateAvatar` — 修改资料
* `queryVipStatus` / `activateVip` — VIP 状态

### 气泡
* `publishBubble` / `updateBubble` — 发布 / 修改气泡
* `queryBubbles` — 按位置查附近气泡
* `queryBubbleInteraction` — 查气泡的点赞/收藏/评论状态
* `likeBubble` / `favoriteBubble` / `commentBubble` — 互动
* `queryBubbleComments` — 评论列表

### 个人中心
* `getUserCenterData` — **一次性拉取** 个人中心所有数据
* `queryUserStats` / `queryUserPublished` / `queryUserLikes` / `queryUserFavorites` / `queryUserComments` / `queryUserViews` — 独立查询
* `searchRecords` — 个人中心内搜索
* `deleteRecords` — 删除记录

### 通知 / 私聊 / 群组
* `queryInboxUnread` / `queryNotificationsByType` / `markNotificationRead`
* `sendPrivateMessage` / `queryPrivateChats` / `queryPrivateMessages` / `queryPrivateUnreadCount`
* `sendFriendRequest` / `acceptFriendRequest` / `rejectFriendRequest` / `queryFriends` / `queryFriendRequests`
* `createGroup` / `queryMyGroups` / `queryGroupMembers` / `sendGroupMessage` / `queryGroupMessages` 等

### 位置 / 通讯
* `position` — 上报位置
* `publicChat` / `chatroomMsg` — 公屏与聊天室
* `privateChat` — 私聊

### 地点服务
* `getProvinces` / `getCitiesByProvince` / `searchCities` — 行政区
* `searchPlaces` / `reverseGeocode` — 关键词搜索 / 逆地理编码

### 管理
* `adminCommand` / `clearBubbles` — 管理员指令

#### 已知本地限制

| 限制 | 原因 | 对策 |
| --- | --- | --- |
| 腾讯地图 SDK 必须在联网环境加载 | SDK 从 CDN 加载 | 开发时保持联网 |
| WebSocket 默认端口 3000 可能被占用 | 其他进程占用 | `taskkill /F /PID <pid>` 或修改端口 |
| 地址搜索依赖外网 | 后端调用第三方 API | 本地开发搜索可能无效，不影响登录/气泡 |
| 数据库文件 `users.db` 与 `SERVER.js` 同目录 | SQLite 文件写入 | `gitignore` 建议忽略 `users.db` |

## 18. 维护提示

* 修改全局状态变量时，**先看 `js/globals.js`** —— 那里集中声明了 `socket` / `map` / `currentUser` / `bubbles` 等，所有 `js/*.js` 文件共享这些变量。
* 修改气泡类型或时长时，**同步修改 `js/publish.js` 的类型定义和 `SERVER.js` 的字段约束**。
* 修改个人中心协议时，**保持 `getUserCenterData`（一次拉取）和 6 个独立查询双轨兼容**，前端已用缓存策略平滑切换。
* 调试时务必先 `DEBUG_WS=1`，否则日志被静默。
* 监控大屏 3001 端口**不要暴露到公网**，包含管理员级操作。
